# cookie-factory
for the hannover game jam 26

Level painting now uses `assets/tilesets/factory.tres`: select **FloorTiles** or
**Props** in `scenes/floor.tscn` and paint from either sprite-pack atlas. The
149 assets use a native 64px grid, replacing individual grid sprite scenes.
See `assets/tilesets/README.md` for rebuilding and multi-cell tile placement.
